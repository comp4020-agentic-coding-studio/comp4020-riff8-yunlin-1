# Source and licence of the seal guides

`guides.json` is derived from the 全字庫說文解字 (CNS11643 Shuowen Jiezi)
small-seal font, made by CMEX for Taiwan's CNS11643 Chinese Standard
Interchange Code site, now run by the Ministry of Digital Affairs. `build.py`
turned 31 of its characters into SVG paths and stroke masks; the font itself
is not in this repository.

The font file used is `ebas927.ttf` (sha256 base32
`1qkljldbmb53zp1rcmpsb8rzy67rnsqcjxi549m9743ifk4isl78`, the hash GNU Guix's
`font-cns11643-swjz` package pins).
